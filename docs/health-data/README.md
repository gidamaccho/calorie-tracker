# ヘルスコネクト データ置き場

ヘルスコネクトからエクスポートしたCSVファイルをこのフォルダに置いてください。

## 置き方

1. スマホのヘルスコネクトアプリ（またはGoogle Fit等）からデータをエクスポート
2. CSVファイルをこのフォルダにコピー
3. コミットしてプッシュ

ファイル名は自由です。例:

```
docs/health-data/
  ├── sleep.csv        # 睡眠データ
  ├── heart_rate.csv   # 心拍データ
  └── steps.csv        # 歩数・活動データ
```

エクスポートが1つのファイルにまとまっている場合は、そのまま1ファイルで置いて構いません。

## 分析内容

CSVが追加されたら、以下を分析します:

- 疲労回復の状況（睡眠時間・睡眠リズム・安静時心拍の推移）
- 活動量の傾向（歩数・心拍ゾーン別時間）とオーバーワーク兆候の有無
- `docs/training-program.md` のプログラムの個別調整
