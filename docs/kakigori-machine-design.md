# ふわふわかき氷機「Quasi-Liquid Shaver QLS-1」設計書

*— 氷の表面物理と切削力学にもとづく、理論的に最高のかき氷 —*

## 0. 要旨

かき氷の「ふわふわ」は偶然の産物ではなく、**(1) 氷表面の準液体層による潤滑、(2) 延性域切削による連続薄片の生成、(3) 摩擦発熱の抑制**という3条件を同時に満たしたときにのみ得られる物理現象である。本書はこの3条件を定式化し、そこから最適な刃の角度・切込み深さ・氷温・回転数を導出し、それを実現する機械 QLS-1 を設計する。

**結論(先に言う)**

| パラメータ | 最適値 | 根拠 |
|---|---|---|
| すくい角 α | **32° ± 3°** | §3.4(切削力最小化と刃先強度の両立) |
| 刃先角(くさび角)δ | **23°** | §3.3(氷の硬度に対する刃先座屈限界) |
| 逃げ角 γ | **5°** | §3.3(仕上げ面の再擦過防止) |
| 斜行角(シヤー角)λ | **20°** | §3.5(実効刃先半径の低減) |
| 切込み深さ t | **40 μm(20–60 μm)** | §3.2(脆性–延性遷移の臨界切込み) |
| 氷温 T | **−4 ± 1 °C** | §2.2(準液体層厚と延性の最適点) |
| 刃先の周速 v | **≤ 0.5 m/s(氷回転 ≈ 60 rpm)** | §3.6(摩擦融解率 ≤ 2 %) |
| 目標ふわふわ度 Φ | **≥ 0.85**(嵩密度 ≤ 140 kg/m³) | §5(官能評価との相関) |

## 1. 「美味しい」の物理的定義

かき氷の官能量を物理量に翻訳する。

1. **口溶け** — 薄片が舌の熱で融けきる時間 τ で決まる。厚さ h の氷片の融解時間は熱伝導律速で
   τ ≈ ρ_ice · L · h² / (2 k_ice · ΔT)
   (L: 融解潜熱 334 kJ/kg、k_ice: 熱伝導率 2.2 W/m·K、ΔT ≈ 36 K)。
   h = 40 μm なら τ ≈ 数ミリ秒 — 「触れた瞬間に消える」。h = 0.5 mm(旧式の粗い削り)では τ が2桁遅く、「ジャリ」と感じる。**薄さこそ正義**。

2. **ふわふわ度 Φ** — 嵩密度 ρ_bulk と氷の真密度 ρ_ice = 917 kg/m³ を用いて
   **Φ = 1 − ρ_bulk / ρ_ice**
   と定義する。薄片がリボン状に湾曲して積み重なり空気を抱き込むほど Φ が上がる。粉砕された角ばった破片は密に詰まり Φ が下がる。つまり **Φ は「破砕せず連続リボンとして削れたか」の指標**である。

3. **シロップ保持力** — 薄片の比表面積 S ∝ 1/h。薄いほど毛管力でシロップを保持し、皿の底に沈まない。これも薄さの関数。

∴ 目的関数は「**破断のない、厚さ数十 μm の連続リボンを、融かさずに量産する**」ことに帰着する。

## 2. 素材物理:氷はなぜ削れるのか

### 2.1 準液体層(Quasi-Liquid Layer)— ファラデー以来の宿題

氷の表面は融点以下でも数 nm の液体様の層(QLL)で覆われている(Faraday, 1850年代の観察に始まり、近年は表面X線散乱・和周波分光で実証)。層厚 d は融点に近づくほど発散的に増加し、経験的に

  d(T) ≈ d₀ · (T_m / (T_m − T))^(1/3) 程度(数 nm 〜 −1 °Cで数十 nm)

この層が**天然の潤滑膜**として働き、刃と氷の摩擦係数を μ ≈ 0.02–0.1 まで下げる。摩擦角 β = arctan μ ≈ **1–6°** という異常に小さい値が、後の角度最適化(§3.4)で効いてくる。

### 2.2 脆性か延性か — 氷温が決める

氷は −5 °C でも均質温度 T/T_m ≈ 0.98 という「融点直下の固体」であり、条件次第で金属のように塑性流動(転位すべり+粒界クリープ)する。

- **冷たすぎる氷(−15 °C 以下)**: 脆性破壊が支配。刃が当たるとリボンにならず**割れて粉になる** → シャリシャリの粗い氷。冷凍庫から出した直後の氷がまずい理由。
- **温かすぎる氷(−1 °C 付近)**: QLL が厚くなりすぎ、削った薄片同士が接触瞬間に焼結(シンタリング)・再凍結して**べちゃっと固まる**。
- **最適 −4 ± 1 °C**: 塑性流動で連続リボンが出せ、かつ薄片が自立する。老舗氷屋が「氷は室温で汗をかかせてから削れ」と言うのは、この温度への**焼き戻し(テンパリング)**である。

∴ **氷温 −4 °C は理論と伝統が一致する点**。QLS-1 はテンパリング庫を内蔵する(§4)。

## 3. 角度の理論 — どの角度が美味しいか

### 3.1 用語(直交切削モデル)

```
              進行方向 →
        ┌─ すくい面
        │α ← すくい角(垂直線から測る)
   薄片 ↗│
  ~~~~~~ ▼____
  氷 ████████│\ δ ← 刃先角(くさび角)
  ██████████│γ\___ 逃げ面(逃げ角 γ)
        切込み深さ t
```

α + δ + γ = 90°(直交切削の幾何拘束)。

### 3.2 ふわふわ条件 I:延性域切削(t ≤ t_c)

脆性材料の切削には臨界切込み深さ t_c が存在し(Bifano らの延性域研削理論)、

  t_c ∝ (E/H) · (K_c/H)²

E: ヤング率 ~9 GPa、H: 硬度(−4 °C で ~30 MPa 程度まで軟化)、K_c: 破壊靱性 ~0.1 MPa·m^½。−4 °C の氷では H が小さいため t_c は **数十〜100 μm** と見積もられ、**t = 40 μm はゆとりを持って延性域**に入る。t を 0.3 mm(家庭用機の典型)にすると t_c を超えて脆性破壊が混入し、Φ が急落する。**刃の出し量を 10 μm 単位で調整できること**が機械要件になる(§4)。

### 3.3 ふわふわ条件 II:薄片を圧縮しない(刃先角とすくい角の下限・上限)

削られた薄片の圧縮比(切削比)は Merchant の直交切削モデルで

  r = t / t_chip = sin φ / cos(φ − α)  … (1)
  φ = 45° + α/2 − β/2         … (2)(せん断角、切削エネルギー最小の条件)

(2) を (1) に入れると、**r = 1(無圧縮のリボン)は β = 0 のとき α によらず達成される**。氷は QLL のおかげで β ≈ 3° と、ほぼ「理想の無摩擦切削」ができる稀有な材料である。ふわふわかき氷が金属切削より簡単なのは、**氷が自分で潤滑油を分泌している**からだ。

ただし切削力(単位幅あたり)は

  F ∝ τ_s · t · cos(β − α) / [sin φ · cos(φ + β − α)]

で、**α を大きくするほど単調に減少**する。力が小さい → 薄片への残留ひずみが小さい → リボンが緩やかにカールして空気を抱く → Φ 上昇。ゆえに α はできる限り大きくしたい。

上限を決めるのは刃先強度である。刃先角 δ = 90° − α − γ が小さすぎると刃先が欠け・びびり振動(チャタリング)を起こし、リボンに周期的な破断が入る(縞々の「なみなみ氷」の正体)。氷の硬度は鋼の1/100 以下なので剃刀並みの δ ≈ 17° まで攻められるが、業務での再研磨性と欠け耐性のマージンをとり **δ = 23°** とする。

### 3.4 最適すくい角の導出

γ = 5°(逃げ角。これ未満だと逃げ面が仕上げ面を擦って摩擦熱で表層を融かす。大きすぎると刃先支持が弱る)を固定すると、

  **α* = 90° − δ − γ = 90° − 23° − 5° = 62°(幾何学的上限)**

…だが、これは静的な上限である。実機では α > 40° で薄片がすくい面を滑走する時間が伸び、すくい面との接触摩擦熱で薄片表面が融け、排出後に再凍結してリボン同士が固着することが知られている(§3.6 の融解率制約)。滑走距離 ∝ 1/cos α で発散的に伸びるため、融解率 2 % 制約(§3.6)を課すと実効上限は α ≈ 35° に落ちる。刃先寿命の統計も加味し、

  **α = 32° ± 3° を最適点として採用する。**

「大きいほど force は下がるが、大きすぎると熱で融ける」— **ふわふわの角度とは、力学と熱力学の綱引きの均衡点**である。

### 3.5 斜行角 λ = 20°:隠し味の角度

刃を進行方向に対して λ だけ斜めに取り付ける(斜め切削)。実効刃先半径が cos λ 倍に、実効切込みも cos λ 倍に低減され、**同じ刃でもより「鋭く」振る舞う**。刺身を引き切りにするのと同じ原理。λ を大きくしすぎると薄片が横に流れて捻れ、破断するため λ = 20° に留める。

### 3.6 ふわふわ条件 III:融かさない(速度上限)

切削+摩擦仕事の単位体積あたりエネルギー u が氷の体積融解熱 ρL = 3.06×10⁸ J/m³ に対して

  x = u / (ρL) ≤ 2 %

を超えると、薄片表面の融液が積層後に再凍結し「口の中でほどけない」塊になる。u は切削速度 v にほぼ比例する発熱項を含むため、**v ≤ 0.5 m/s** を課す。半径 4 cm の氷塊なら **約 60 rpm** — ハンドルをゆっくり回す手動かき氷機の速度が、実は熱力学的に正しかったことになる。電動化する場合も高速化は禁物で、トルク重視の低速モータを使う。

## 4. 機械設計 QLS-1

### 4.1 構成

```
        ┌──────────────────────────┐
        │  ハンドル / 60rpm ギヤードモータ      │
        │      │                   │
        │  ┌───▼────┐  スパイク3本で氷を把持    │
        │  │ 回転スピンドル │                 │
        │  └───┬────┘                 │
        │   ┌──▼──┐   ┌ 氷温センサ(−4°C監視) │
        │   │ 氷塊  │◄──┘                │
        │   └──┬──┘                   │
        │  ════╪════ ◄─ 刃ユニット          │
        │      │   α=32° δ=23° γ=5° λ=20°  │
        │      │   出し量: マイクロメータ 10μm/目盛 │
        │   ふわふわ薄片(t=40μm リボン)         │
        │      ▼                    │
        │   ┌─────┐                 │
        │   │ 器    │ ターンテーブル(手動回し)   │
        │   └─────┘                 │
        ├──────────────────────────┤
        │ テンパリング庫: −4±1°C ペルチェ制御       │
        └──────────────────────────┘
```

### 4.2 仕様

| 項目 | 仕様 | 備考 |
|---|---|---|
| 刃材 | ハイス鋼 SKH51、鏡面ラップ仕上げ | 刃先半径 ≤ 2 μm。すくい面粗さが薄片の破断起点になるため鏡面必須 |
| 刃保持 | α=32°/γ=5°/λ=20° 固定ジグ + 剛性ブロック | びびり防止に刃の突き出しを最小化 |
| 切込み調整 | 差動ネジ式マイクロメータ、1目盛 10 μm | §3.2 の t_c 管理のため必須。「ネジ半回転で味が変わる」 |
| 氷把持 | 3点スパイク+定荷重バネ | 過大な軸押付けは氷内部に応力を残し破砕の種になる |
| 駆動 | 手動ハンドル or 60 rpm ギヤードモータ | §3.6 の速度上限 |
| テンパリング庫 | ペルチェ ±0.5 °C 制御、−4 °C | 冷凍庫(−18 °C)の氷は最低 30 分焼き戻す |
| 氷 | 純水をゆっくり一方向凝固させた単結晶様氷が理想 | 気泡・粒界は破断の起点。市販の「純氷」でも可 |

### 4.3 運転手順(プロトコル)

1. 氷塊をテンパリング庫で −4 °C に整える(急ぐと内外温度差で内部応力 → 割れる)。
2. 刃の出し量をゼロ点から +4 目盛(40 μm)。
3. 60 rpm で削る。**リボンが半透明の連続カールで落ちれば成功**。粉が混じれば氷が冷たすぎ、濡れて見えれば速すぎか温すぎ。
4. 器を回しながら受け、押さえつけずに山を積む(Φ を潰さない)。

## 5. 検証:ふわふわ度の測定

官能評価は再現性が低いので、物理量で合否判定する。

- **嵩密度法**: 既知体積の容器に削り氷を無圧充填し秤量。Φ = 1 − ρ_bulk/917。**合格ライン Φ ≥ 0.85(ρ_bulk ≤ 140 kg/m³)**。
- **融解時間法**: 36 °C の銅板に単一薄片を載せ、消失までを高速度カメラで測定。τ ≤ 10 ms を合格とする。
- **リボン連続長**: 1 削りあたりの無破断リボン長 ≥ 50 mm。

パラメータ感度(理論予測):Φ は t に対して t_c 近傍で崖状に劣化し、α に対しては 32° 近傍で緩やかな最大値を持つ。**まず氷温、次に切込み、最後に角度**の順で追い込むのが実験計画として効率的である。

## 6. 結論

ふわふわかき氷とは、**融点直下の氷が示す準液体層潤滑と塑性流動を利用した、無摩擦・無圧縮に近い延性域マイクロ切削**である。最も美味しい角度は

**すくい角 32°(刃先角 23°、逃げ角 5°、斜行角 20°)、切込み 40 μm、氷温 −4 °C、刃速 0.5 m/s 以下。**

角度だけが答えではない — 角度・深さ・温度・速度の4変数が同時に揃ったとき、氷は粉ではなくリボンになり、リボンは空気を抱いて雪になる。

*(本設計書の数値は公表されている氷の物性値と古典切削理論からの見積もりであり、実機での検証実験を推奨する。検証、それが物理学者の流儀である。)*
