# Ableton Live キーボード説明書

Ableton Live を「キーボード」で操作するための実用ガイドです。以下の3つを扱います。

1. **コンピューターMIDIキーボード** — PCのタイピングキーボードを鍵盤として使う
2. **キーボードショートカット** — Live本体の操作を速くする
3. **ハードウェアMIDIキーボード** — 外部鍵盤の接続・設定・マッピング

対象バージョン: **Ableton Live 11 / 12**（Intro・Standard・Suite 共通。一部機能はエディション依存）
表記: `Cmd` = macOS、`Ctrl` = Windows。`Alt` は macOS では `Option` を指します。

## 1. コンピューターMIDIキーボード

MIDIキーボードが手元になくても、PCのキーボードをそのまま鍵盤として使えます。

### オン／オフ

| 操作 | キー |
| --- | --- |
| コンピューターMIDIキーボードの有効／無効 | `M` |

右上のツールバーにあるピアノ鍵盤アイコンが点灯していれば有効です。

> **重要:** 有効中は `A`〜`L` などの文字キーが鍵盤として動作するため、**それらを使うショートカットは効かなくなります**。ショートカットを使いたいときは `M` でオフに戻してください。

### 鍵盤の配列

タイピングキーボードの中段・上段がピアノ配列に対応します。

```
黒鍵:      W  E     T  Y  U
白鍵:    A  S  D  F  G  H  J  K
音名:    C  D  E  F  G  A  B  C
```

- 中段 `A S D F G H J K` = 白鍵（ド・レ・ミ・ファ・ソ・ラ・シ・ド）
- 上段 `W E / T Y U` = 黒鍵（ド♯・レ♯ / ファ♯・ソ♯・ラ♯）

### オクターブとベロシティ

| 操作 | キー |
| --- | --- |
| オクターブを下げる | `Z` |
| オクターブを上げる | `X` |
| ベロシティを下げる | `C` |
| ベロシティを上げる | `V` |

ベロシティは20刻みで変化します。実際に音を出すには、対象のMIDIトラックを選択して**録音アームを有効**にしておく必要があります。

### 使いどころ

- 外出先・移動中でのスケッチ
- ドラムラックの試聴（`Z`/`X` でパッドのバンクを移動）
- インストゥルメントのプリセット選びで、ブラウザーをプレビューしながら試し弾き

## 2. キーボードショートカット

> 一部のショートカットはバージョンやエディションで異なる場合があります。手元のLiveで確認するには、公式マニュアル巻末の「キーボードショートカット」一覧を参照してください。

### 2.1 再生・録音

| 操作 | Mac | Windows |
| --- | --- | --- |
| 再生／停止 | `Space` | `Space` |
| 停止位置から再生を継続 | `Shift` + `Space` | `Shift` + `Space` |
| 録音 | `F9` | `F9` |
| アレンジメントに戻る（Back to Arrangement） | `F10` | `F10` |
| ループのオン／オフ | `Cmd` + `L` | `Ctrl` + `L` |
| MIDIキャプチャ | `Cmd` + `Shift` + `C` | `Ctrl` + `Shift` + `C` |
| インサートマーカーを開始位置へ | `Home` | `Home` |
| インサートマーカーを終了位置へ | `End` | `End` |

**MIDIキャプチャ**は、録音していない状態で弾いた直後に押すと、直前の演奏をクリップとして拾ってくれる機能です。「今のフレーズ良かったのに録ってなかった」を救済します。

### 2.2 ファイル・編集

| 操作 | Mac | Windows |
| --- | --- | --- |
| 新規Liveセット | `Cmd` + `N` | `Ctrl` + `N` |
| 開く | `Cmd` + `O` | `Ctrl` + `O` |
| 保存 | `Cmd` + `S` | `Ctrl` + `S` |
| 名前を付けて保存 | `Cmd` + `Shift` + `S` | `Ctrl` + `Shift` + `S` |
| オーディオ／ビデオを書き出し | `Cmd` + `Shift` + `R` | `Ctrl` + `Shift` + `R` |
| 元に戻す | `Cmd` + `Z` | `Ctrl` + `Z` |
| やり直す | `Cmd` + `Shift` + `Z` | `Ctrl` + `Shift` + `Z` |
| コピー / カット / ペースト | `Cmd` + `C` / `X` / `V` | `Ctrl` + `C` / `X` / `V` |
| 複製 | `Cmd` + `D` | `Ctrl` + `D` |
| 名前の変更 | `Cmd` + `R` | `Ctrl` + `R` |
| 環境設定 | `Cmd` + `,` | `Ctrl` + `,` |

**`Cmd/Ctrl` + `D`（複製）は最頻出です。** クリップ、トラック、シーン、ノート、デバイス、オートメーションのブレークポイントまで、選択中のほぼ何でも複製できます。

### 2.3 ビュー切り替え

| 操作 | Mac | Windows |
| --- | --- | --- |
| セッション／アレンジメント切り替え | `Tab` | `Tab` |
| クリップ／デバイスビュー切り替え | `Shift` + `Tab` | `Shift` + `Tab` |
| ブラウザーの表示／非表示 | `Cmd` + `Alt` + `B` | `Ctrl` + `Alt` + `B` |
| 詳細ビューの表示／非表示 | `Cmd` + `Alt` + `L` | `Ctrl` + `Alt` + `L` |
| オーバービューの表示／非表示 | `Cmd` + `Alt` + `O` | `Ctrl` + `Alt` + `O` |
| インフォビューの表示／非表示 | `Cmd` + `Alt` + `I` | `Ctrl` + `Alt` + `I` |
| センドの表示／非表示 | `Cmd` + `Alt` + `S` | `Ctrl` + `Alt` + `S` |
| ミキサーの表示／非表示 | `Cmd` + `Alt` + `M` | `Ctrl` + `Alt` + `M` |
| フルスクリーン | `Cmd` + `Ctrl` + `F` | `F11` |
| ズームイン／アウト | `+` / `-` | `+` / `-` |

**`Tab` と `Shift` + `Tab` の2つを体に入れるだけで、作業速度が明確に変わります。**

### 2.4 トラック操作

| 操作 | Mac | Windows |
| --- | --- | --- |
| オーディオトラックを挿入 | `Cmd` + `T` | `Ctrl` + `T` |
| MIDIトラックを挿入 | `Cmd` + `Shift` + `T` | `Ctrl` + `Shift` + `T` |
| リターントラックを挿入 | `Cmd` + `Alt` + `T` | `Ctrl` + `Alt` + `T` |
| グループ化 | `Cmd` + `G` | `Ctrl` + `G` |
| グループ解除 | `Cmd` + `Shift` + `G` | `Ctrl` + `Shift` + `G` |
| ソロ | `S` | `S` |
| 録音アーム | `C` | `C` |
| 有効／無効（ミュート） | `0` | `0` |
| 隣のトラックへ移動 | `←` / `→` | `←` / `→` |

> `S` `C` `0` は**コンピューターMIDIキーボードがオフのとき**に機能します（`C` はオン時だとベロシティ調整になります）。

### 2.5 クリップ・ノート編集

| 操作 | Mac | Windows |
| --- | --- | --- |
| ドローモード切り替え | `B` | `B` |
| オートメーションモード切り替え | `A` | `A` |
| クオンタイズ | `Cmd` + `U` | `Ctrl` + `U` |
| クオンタイズ設定 | `Cmd` + `Shift` + `U` | `Ctrl` + `Shift` + `U` |
| 分割（Split） | `Cmd` + `E` | `Ctrl` + `E` |
| 結合（Consolidate） | `Cmd` + `J` | `Ctrl` + `J` |
| クリップをクロップ | `Cmd` + `Shift` + `J` | `Ctrl` + `Shift` + `J` |
| ループ範囲を選択範囲に設定 | `Cmd` + `Shift` + `L` | `Ctrl` + `Shift` + `L` |
| ノートを半音上げる／下げる | `↑` / `↓` | `↑` / `↓` |
| ノートを1オクターブ上げる／下げる | `Shift` + `↑` / `↓` | `Shift` + `↑` / `↓` |
| グリッドを細かく／粗く | `Cmd` + `1` / `2` | `Ctrl` + `1` / `2` |
| 3連符グリッド切り替え | `Cmd` + `3` | `Ctrl` + `3` |
| グリッドのスナップ切り替え | `Cmd` + `4` | `Ctrl` + `4` |

**ノート編集の実務では、`Cmd/Ctrl` + `1` / `2` でグリッドを刻み替えながら打ち込むのが基本の型です。**

### 2.6 セッションビュー

| 操作 | キー |
| --- | --- |
| 選択中のクリップ／シーンを再生 | `Enter` |
| クリップの選択を移動 | `↑` `↓` `←` `→` |
| 選択したクリップを停止 | `0`（無効化）または停止ボタン |
| シーンを挿入 | `Cmd/Ctrl` + `I` |
| 現在の状態からシーンをキャプチャして挿入 | `Cmd/Ctrl` + `Shift` + `I` |

**「キャプチャして挿入」**は、いま鳴っている組み合わせをそのまま新しいシーンに固定する機能で、ライブセットの構成作りで強力です。

### 2.7 アレンジメントビュー

| 操作 | Mac | Windows |
| --- | --- | --- |
| 選択範囲に無音を挿入 | `Cmd` + `I` | `Ctrl` + `I` |
| 時間を削除（詰める） | `Cmd` + `Shift` + `X` | `Ctrl` + `Shift` + `X` |
| ロケーターを追加 | `Cmd` + `Shift` + `L`（設定による） | 同左 |
| 選択範囲にズーム | `Alt` + `Z` | `Alt` + `Z` |
| フォロー（再生位置追従）切り替え | `Cmd` + `Shift` + `F` | `Ctrl` + `Shift` + `F` |

### 2.8 ブラウザー

| 操作 | Mac | Windows |
| --- | --- | --- |
| ブラウザー内を検索 | `Cmd` + `F` | `Ctrl` + `F` |
| プレビュー再生 | `Shift` + `Enter` | `Shift` + `Enter` |
| 選択トラックに読み込む | `Enter` | `Enter` |
| フォルダーを開く／閉じる | `→` / `←` | `→` / `←` |

## 3. ハードウェアMIDIキーボード

### 接続手順

1. USB（またはMIDIインターフェース経由でMIDIケーブル）でキーボードをPCに接続します。**Liveを起動する前に接続**しておくのが確実です。
2. Liveを起動し、`Cmd/Ctrl` + `,` で環境設定を開きます。
3. **Link / Tempo / MIDI**（Live 11以降は「Link, Tempo & MIDI」）タブを開きます。
4. **MIDI Ports** のリストに接続したキーボードが表示されていることを確認します。

### ポート設定の3つのスイッチ

各入力ポートには3つのトグルがあります。役割を取り違えると「音が出ない」の典型的な原因になります。

| スイッチ | 役割 | 鍵盤で演奏したいとき |
| --- | --- | --- |
| **Track** | ノートやCCをトラックに送る | **オン**（必須） |
| **Sync** | MIDIクロックの送受信 | オフでよい |
| **Remote** | Liveのパラメーターへのマッピングに使う | ノブ／フェーダーを割り当てるなら**オン** |

演奏だけなら **Track をオン**。ノブでフィルターを動かしたいなら **Remote もオン**にします。

### 音を出すまでのチェックリスト

1. MIDIトラックを1つ用意する（`Cmd/Ctrl` + `Shift` + `T`）
2. インストゥルメント（例: Drift、Wavetable、Simpler）をトラックにドラッグする
3. トラックの **MIDI From** が `All Ins`（または該当キーボード）になっている
4. トラックの**録音アームボタン**（丸いボタン）を点灯させる
5. 鍵盤を弾く → メーターが振れて音が鳴る

### コントロールサーフェス（自動マッピング）

Ableton が対応表を持っているキーボードなら、環境設定の **MIDI** タブ上部で自動設定できます。

1. **Control Surface** のドロップダウンから機種名を選ぶ
2. **Input** / **Output** にそのキーボードのポートを指定する

これでトランスポートボタンやノブが自動的に機能します。機種名が一覧にない場合は、次章の手動マッピングを使ってください。

## 4. MIDIマッピングとキーマッピング

Live の画面上のほぼすべてのコントロールに、MIDI信号やPCのキーを割り当てられます。

### MIDIマッピング（外部コントローラー → Live）

| 操作 | Mac | Windows |
| --- | --- | --- |
| MIDIマップモードのオン／オフ | `Cmd` + `M` | `Ctrl` + `M` |

**手順:**

1. `Cmd/Ctrl` + `M` でマップモードに入る（画面が青紫にハイライトされます）
2. 割り当てたいコントロール（例: フィルターのカットオフ）をクリック
3. キーボードのノブを回す、または鍵盤を押す
4. `Cmd/Ctrl` + `M` でマップモードを抜ける

左側のマッピングブラウザーに一覧が出るので、不要なものは選択して `Delete` で解除できます。

### キーマッピング（PCキーボード → Live）

| 操作 | Mac | Windows |
| --- | --- | --- |
| キーマップモードのオン／オフ | `Cmd` + `K` | `Ctrl` + `K` |

手順は MIDI マッピングと同じで、手順3でPCのキーを押します。クリップの launch を数字キーに割り当てる、といった使い方ができます。

> **注意:** キーマッピングしたキーは、Live標準のショートカットより優先されます。`S` や `C` など既存ショートカットのキーに割り当てると、元の機能が使えなくなります。

## 5. よくあるトラブル

| 症状 | 原因と対処 |
| --- | --- |
| 文字キーを押すと音が鳴ってショートカットが効かない | コンピューターMIDIキーボードがオン。`M` でオフにする |
| 鍵盤を弾いても音が鳴らない | トラックの録音アームがオフ／`MIDI From` が違う／環境設定で **Track** がオフ |
| 環境設定にキーボードが出てこない | Liveを再起動する。USBハブ経由なら直挿しを試す。専用ドライバーの有無を確認する |
| 音は鳴るが遅れる（レイテンシー） | 環境設定 **Audio** で Buffer Size を下げる。Windowsでは ASIO ドライバーを使う |
| ノブを動かすと関係ないパラメーターが動く | 意図しないMIDIマッピングが残っている。`Cmd/Ctrl` + `M` でマッピングブラウザーを開き、該当項目を削除する |
| 打鍵の強弱が反映されない | インストゥルメント側でベロシティが音量にルーティングされていない。Simpler なら Volume の Vel 量を上げる |
| ノートがずっと鳴りっぱなし | ケーブルを抜き差しするとNote Offが失われることがある。トラックのアームを外す／Liveを再起動する |

## 6. 覚える順番（おすすめ）

一度に全部は覚えられないので、この順で身につけるのが効率的です。

**第1段階 — これだけで日常操作の8割**

- `Space`（再生／停止）
- `Tab`（セッション／アレンジメント）
- `Cmd/Ctrl` + `D`（複製）
- `Cmd/Ctrl` + `Z`（元に戻す）
- `Cmd/Ctrl` + `S`（保存）

**第2段階 — 打ち込みが速くなる**

- `M`（コンピューターMIDIキーボード）と `Z` `X`（オクターブ）
- `B`（ドローモード）
- `Cmd/Ctrl` + `1` / `2`（グリッド）
- `Cmd/Ctrl` + `U`（クオンタイズ）
- `Cmd/Ctrl` + `L`（ループ）

**第3段階 — 構成づくりとミックス**

- `Shift` + `Tab`（クリップ／デバイス）
- `Cmd/Ctrl` + `E` / `J`（分割／結合）
- `Cmd/Ctrl` + `G`（グループ化）
- `A`（オートメーション）
- `Cmd/Ctrl` + `Shift` + `C`（MIDIキャプチャ）

**第4段階 — 自分仕様にする**

- `Cmd/Ctrl` + `M`（MIDIマッピング）
- `Cmd/Ctrl` + `K`（キーマッピング）
