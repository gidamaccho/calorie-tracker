## 1. 戦略の核(テーゼ)

### 1.1 突く非効率

本戦略は**「企業固有情報への過小反応(underreaction)」**を収益源とする。

1. **情報の緩慢な拡散(slow information diffusion)** — 決算・ガイダンス・アナリスト予想修正などの企業固有ニュースは、発表後も数週間〜数ヶ月かけて価格に織り込まれる(Post-Earnings Announcement Drift はその代表例)。
2. **アンカリングと処分効果** — 投資家は取得価格や直近の株価水準にアンカーし、良いニュース後の上昇局面で早売りし、悪いニュース後の下落局面で塩漬けにする。これが企業固有リターンの自己相関(モメンタム)を生む。
3. **なぜ「残差」か** — 生の株価モメンタム(いわゆる 12-1 モメンタム)はリターンの大半が市場・セクター・スタイルファクターの共通変動で説明され、2009年型の「モメンタム・クラッシュ」(ファクター反転時の急落)に脆弱。**ファクター起因のリターンを回帰で剥ぎ取った残差にのみモメンタムを取る**ことで、(a) 企業固有の過小反応という行動バイアスに純化し、(b) クラッシュ耐性を高め、(c) 裁定資本の混雑(crowding)が集中する生モメンタムから距離を置く。

### 1.2 エッジが持続すると考える理由

- 収益源が**行動バイアス+機関投資家の制度的制約**(ベンチマーク運用者は残差リターンを積極的に取りにいけない)にあり、単純な計算高速化では消えない。
- ただしエッジは**必ず劣化する**前提で設計する(§10)。「効き続ける根拠」より「効かなくなったことを検知する仕組み」を重視する。

### 2.2 不採用としたもの

- **小型株**:シグナルは強いが、借株コスト・マーケットインパクトで実現アルファが消える。10Bドル運用では容量的に不可。
- **オプション**:本戦略のシグナルは方向性・水平線とも「株式の残差リターン」に対して定義されており、ベガ・セータのノイズを持ち込む理由がない。ヘッジもβが線形なので先物で十分。
- **新興国株**:執行・カストディ・データのオペレーショナルリスクが期待アルファに見合わない。

## 3. シグナル生成ロジック

### 3.1 レジデュアル・モメンタム(主シグナル、ウェイト 60%)

各銘柄 $i$ について、直近 36ヶ月の月次リターンで地域別ファクターモデルに回帰:

$$
r_{i,t} = \alpha_i + \beta_i^{MKT} \, MKT_t + \beta_i^{SMB} \, SMB_t + \beta_i^{HML} \, HML_t + \beta_i^{SEC} \, SEC_t + \varepsilon_{i,t}
$$

- $MKT, SMB, HML$:地域別ファクターリターン、$SEC$:所属セクターの超過リターン
- 残差 $\hat\varepsilon_{i,t}$ を取り出し、**直近12ヶ月から直近1ヶ月を除いた期間**(t−12 〜 t−2)で集計:

$$
\text{rMOM}_i = \frac{\sum_{s=t-12}^{t-2} \hat\varepsilon_{i,s}}{\sigma(\hat\varepsilon_{i})\sqrt{11}}
$$

直近1ヶ月(t−1)を除くのは短期リバーサル(1ヶ月反転効果)の汚染を避けるため。残差の標準偏差で割ることで「情報の強さ/ノイズ」に正規化する(シャープ化)。

### 3.2 業績修正オーバーレイ(補助シグナル、ウェイト 30%)

$$
\text{REV}_i = \frac{\#\text{up}_{i,3m} - \#\text{down}_{i,3m}}{\#\text{total}_{i,3m}} \times w_{\text{disp}}, \qquad w_{\text{disp}} = \frac{1}{1 + \text{予想のばらつき(CV)}}
$$

- 直近3ヶ月の EPS 予想の上方/下方修正件数の純比率。アナリスト間のばらつきが大きい銘柄はウェイトを減衰。
- 残差モメンタムと同一の行動テーゼ(過小反応)を、価格ではなく**ファンダメンタルズ側から**測る確認シグナル。

### 3.3 短期リバーサル・フィルター(ウェイト 10%、逆符号)

$$
\text{STR}_i = -z\left(r_{i,\,t-5:t}^{\text{residual}}\right)
$$

直近5営業日の残差リターンのZスコアの符号反転。直近に急騰した銘柄の新規ロングを抑制し、エントリー価格の質を上げる(実質的には執行タイミングの調整弁)。

### 3.4 コンポジット・スコア

各シグナルを**地域×セクター内でクロスセクショナルにZスコア化**し(±3でウィンザライズ)、合成:

$$
S_i = 0.6 \cdot z(\text{rMOM}_i) + 0.3 \cdot z(\text{REV}_i) + 0.1 \cdot z(\text{STR}_i)
$$

セクター内で標準化する時点でセクター中立性の大半が担保される(残余は最適化の制約で処理、§6)。

## 4. エントリールール

新規ポジションは以下を**すべて**満たした場合のみ建てる:

1. **シグナル閾値**:$|S_i| \geq 0.75$(クロスセクショナルZスコア)。ロングは $S_i \geq +0.75$、ショートは $S_i \leq -0.75$。
2. **シグナル持続性**:直近5営業日中3日以上で閾値超過(1日だけのスパイクでは建てない)。
3. **ユニバース条件**(§2.3)を当日時点で充足。
4. **イベント・ブラックアウト**:決算発表の2営業日前〜1営業日後は新規建て禁止(既存は保持可)。
5. **キャパシティ**:注文予定数量が当該銘柄 ADV の 2% 以下。超える場合はサイズを切り詰め。
6. **ポートフォリオ制約**(§6)に違反しないこと。違反する場合、最適化がサイズを自動縮小。
7. **執行**:成行は使わない。VWAP/IS(Implementation Shortfall)アルゴで当日〜翌日にかけて分割執行。想定コスト(§8のコストモデル)が期待アルファの 30% を超える注文は棄却。

## 6. ポジションサイジング

### 6.1 基本原理:ボラティリティ・ターゲティング+シグナル比例

銘柄 $i$ の生ウェイト:

$$
w_i^{raw} = \frac{S_i}{\hat\sigma_i} \Big/ \sum_j \frac{|S_j|}{\hat\sigma_j}
$$

- $\hat\sigma_i$:EWMA(半減期20日)による予測ボラティリティ。**確信度(シグナル強度)に比例し、リスク(ボラ)に反比例**が原則。

### 6.2 ポートフォリオ・レベルのスケーリング

$$
w_i = w_i^{raw} \times \frac{\sigma_{target}}{\hat\sigma_{ptf}}, \qquad \sigma_{target} = 6\%(年率)
$$

$\hat\sigma_{ptf}$ は銘柄共分散行列(ファクターモデル+特異リスク)から算出。市場ボラが上がれば自動的にグロスを落とす。

### 6.3 ハードリミット

```
単一銘柄:            |w_i| ≤ 1.0%(NAV比)
単一銘柄流動性:      |ポジション| ≤ ADV_60d × 5%(全量5日以内に撤退可能)
グロス・レバレッジ:  ≤ 4.0x(ロング200% / ショート200%を上限)
新規建て刻み:        目標ウェイトへは3営業日に分けて到達(1日最大1/3)
```

ケリー基準は**参照のみ**(推定誤差に過敏なためフルケリーは使わない)。実効サイズはケリーの概ね 1/4 相当になるよう $\sigma_{target}$ を設定している。

## 8. バックテスト設計

### 8.1 データ規律(ここで手を抜くと全部が嘘になる)

| 項目 | 要件 |
|---|---|
| 価格・財務データ | **ポイント・イン・タイム**(その日に実際に入手可能だった値のみ。財務データは発表ラグ+報告遅延を反映) |
| ユニバース | **上場廃止銘柄を含む**(サバイバーシップ・バイアス排除)。過去の指数構成も当時のもの |
| アナリスト予想 | 修正の配信タイムスタンプベース。当日修正は翌営業日から使用可 |
| コーポレートアクション | 分割・配当・スピンオフを調整済みリターンで処理 |

### 8.2 コスト・執行モデル

$$
\text{Cost}_i = \underbrace{\text{spread}_i / 2}_{\text{半スプレッド}} + \underbrace{k \cdot \sigma_i \sqrt{\frac{Q_i}{ADV_i}}}_{\text{マーケットインパクト(平方根則)}} + \text{手数料} + \text{借株料}
$$

- $k$ は自社執行データでキャリブレーション(初期値 0.7)。
- 約定は**シグナル確定の翌営業日 VWAP**(look-ahead 排除)。同日クローズ約定でのバックテストは禁止。

### 8.3 検証プロトコル

```
1. In-sample設計:      2004–2014 でシグナル定義・パラメータを固定
2. Out-of-sample:      2015–2023 は一切触らず一発検証
3. Walk-forward:        3年学習→1年検証をローリング。パラメータ再推定は年1回のみ
4. Purged K-Fold CV:    ラベル期間の重複を除去(embargo = 21営業日)して過学習チェック
5. パラメータ感応度:    閾値±25%、ルックバック±3ヶ月で IR が半分以下にならないこと
6. Deflated Sharpe:     試行回数を申告し、多重検定調整後の Sharpe で判定(DSR > 0.95)
7. 容量テスト:          運用額 1B/5B/10B ドルでコスト込み IR を再計算
8. 採用基準:            OOSで IR ≥ 0.7、最大DD ≤ 15%、月次勝率 ≥ 55%、
                        コスト後アルファの t 値 ≥ 3.0
```

**禁止事項**:OOS期間を見た後のパラメータ変更(=OOSのin-sample化)。変更したくなったら、それは研究のやり直しであり、新たなOOS期間(=将来の実運用データ)が必要。試行したバリエーションはすべて記録し、Deflated Sharpe の分母に入れる。

### 8.4 擬似コード(日次バッチ)

```python
def daily_pipeline(date):
    univ = build_universe(date)                        # §2.3 PITフィルター
    resid = {}
    for stock in univ:
        betas = regress_36m_monthly(stock, factors[region(stock)])  # §3.1
        resid[stock] = stock.returns - betas @ factor_returns

    rmom = {s: sum(resid[s][t-12:t-2+1]) / (std(resid[s]) * sqrt(11)) for s in univ}
    rev  = {s: revision_score(s, window="3m") for s in univ}         # §3.2
    strv = {s: -zscore(resid[s].last_5d.sum()) for s in univ}        # §3.3

    S = {s: 0.6*zs(rmom, s) + 0.3*zs(rev, s) + 0.1*zs(strv, s)
         for s in univ}   # zs = セクター内Zスコア, ±3 winsorize

    signals = apply_entry_exit_rules(S, positions, date)  # §4, §5
    target_w = optimize(
        signals,
        risk_model=factor_cov(date),
        objective="max_alpha - λ·risk - cost_penalty",
        constraints=HARD_LIMITS,                          # §6.3, §7.1
    )
    orders = schedule_orders(target_w - current_w,
                             algo="IS", horizon="1-2d",
                             max_participation=0.02)
    return orders
```

## 10. エッジ劣化の監視

エッジは「あるかないか」ではなく「どの速度で死んでいるか」で管理する。

### 10.1 モニタリング指標(すべて日次〜週次で自動計算・ダッシュボード化)

1. **ローリングIC(情報係数)**
   $$IC_t = \text{RankCorr}\left(S_{i,t-21},\ r^{resid}_{i,\,t-21:t}\right)$$
   12ヶ月ローリング平均ICが in-sample 平均の 50% を下回ったら黄信号、ゼロを statistically 下回ったら赤信号。

2. **CUSUM検定(構造変化検知)** — 日次PnLの累積和を監視:
   $$C_t = \max\left(0,\ C_{t-1} + (x_t - \mu_0 + \delta)\right)$$
   $\mu_0$=期待日次リターン、$\delta$=許容劣化幅。$C_t > h$(閾値)で「平均リターンの構造的低下」をアラート。

3. **ドローダウンの統計的異常判定** — バックテストPnLのブートストラップから「正常なDD分布」を生成。実現DDがその 99パーセンタイルを超えたら、それは運が悪いのではなく**モデルが壊れた**と推定し、デリスク(§7.1と連動)。

4. **混雑(crowding)指標** — (a) ショートサイドの借株料の趨勢的上昇、(b) 同型シグナル銘柄群のペア相関上昇、(c) 13F類推による同業ポジション重複度。混雑スコア上位10%の局面ではグロスを 70% に抑制。

5. **執行品質の劣化** — 実現スリッページ/モデル予測スリッページの比率が 1.3 を超えて定着 → 容量超過またはアルファの高速化(=より速いプレーヤーに先回りされている)を疑う。

### 10.2 ガバナンス

- **月次**:戦略委員会でIC・α t値・混雑スコアをレビュー。
- **半期**:シグナル再検証(ただしパラメータ変更は年1回の再推定枠のみ。§8.3)。
- **停止基準**:24ヶ月ローリングのコスト後αの t 値が 0 を下回る、または赤信号が2系統同時点灯で新規建て停止。復活には新規OOS証跡が必要。
- **原則**:悪いのが「運」か「モデル」かをその場の裁量で判断しない。判断基準は事前に(いま、この文書で)決めておく。
